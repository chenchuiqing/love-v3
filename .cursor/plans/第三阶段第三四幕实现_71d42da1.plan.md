## 第三幕：信封现身（`startAct3`）

### 过渡入场
1. 粒子从 0 opacity 渐显（0.86），照片 img 同步淡出
2. 调用 `computeEnvelopePositions()` 计算信封形状目标点
3. GSAP morph：粒子从照片位置流沙式下坠至信封形状（`power2.in`，1.6s）
4. 粒子颜色过渡：银白 → 暖金色（r=1, g=0.88, b=0.6）

### 信封粒子形态（`computeEnvelopePositions`）
- 60% 粒子：矩形体填充（`w=1.6, h=1.1`，居中偏下 `cy=-0.3`）
- 20% 粒子：V 形内折线（两条对角线，从底角到中心顶）
- 12% 粒子：封口三角翼（闭合的信封盖）
- 8% 粒子：蜡印圆簇（中心密集圆形）

### 交互
- 信封成形后显示提示文字 `"轻轻滑开，看看里面"`
- 用户点击/上滑触发 `openEnvelope()`：
  - 封口三角粒子向上散开（scatter 动画 0.5s）
  - 淡入半透明信纸 HTML overlay
  - 打字机效果逐字显现告白文案（三句话，`CONFESSION_LINES` 常量，可配置）
  - 全文展示完毕后等待 2.5s，自动调用 `startAct4()`

### UI overlay（`v-if="showLetterContent"`）
- 半透明深色背景 + 毛玻璃卡片
- 装饰性上边栏（细线 + 日期）
- 打字机文字区域
- 底部小花纹装饰

## 第四幕：玫瑰绽放（`startAct4`）

### 入场序列
1. 隐藏信纸 overlay，`currentAct = 4`
2. 单颗粒子从信封中心飞出，沿螺旋路径运动（GSAP path tween）
3. 全体粒子 morph：信封 → 3D 玫瑰（2.0s，`power2.inOut`）
4. 同步粒子颜色过渡：暖金 → 深红（r=0.9, g=0.08, b=0.1）

### 玫瑰粒子形态（`computeRosePositions`）
参数化曲面，5 外花瓣 + 5 内花瓣 + 中心圆锥：
- **外花瓣**（55%）：每瓣以 Y 轴为中心按角度旋转，`u∈[0,1]` 控制从底部到花尖，`φ` 控制宽度展开，高度曲线 `sin(u*π)*0.25`
- **内花瓣**（30%）：与外花瓣同形但半径缩小 0.55 倍，角度偏转 36°，整体抬高
- **花心**（15%）：小球体聚簇（`r<0.2`，`y∈[0.15,0.45]`）

### 驻留状态与交互
- 玫瑰进入"永续绽放"：animate 循环让花瓣粒子微幅呼吸浮动
- **拖拽旋转**：act4 下 pointerdown/move 驱动 `particles.rotation.x/y`（带惯性阻尼）
- **点击触觉**：调用 `navigator.vibrate(50)`，浮现文字 `"我的心，始终随你而动。"`（2s 后淡出）
- 进入 act4 后 2s 显示右下角 `"留住这一刻"` 按钮

### 纪念海报保存（`handleSave`）
- 用 2D canvas 合成：WebGL canvas + 告白文字叠层
- 触发 `<a download>` 保存为 PNG，无水印
