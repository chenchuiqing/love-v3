# 实现第一阶段：初见（星尘环绕）

## 1. 依赖安装
- 安装核心 3D 库：`three` 和 `@types/three`
- 安装动画库：`gsap`（用于处理长按交互时平滑的参数补间动画）

## 2. 组件架构设计
- **`src/components/PhaseOne.vue`**: 封装第一阶段的全部逻辑。
  - 包含一个 `<canvas>` 容器用于 Three.js 渲染。
  - 包含一个 UI 覆盖层，显示“按住屏幕”的提示文字（带有呼吸动画）。
- **`src/App.vue`**: 引入 `PhaseOne.vue`，并准备好状态管理（如 `currentPhase`），以便后续阶段切换。

## 3. Three.js 核心实现
- **场景与相机**：
  - 初始化 `Scene`，背景色设置为极深的海军蓝（如 `#000010`）。
  - 初始化 `PerspectiveCamera` 和 `WebGLRenderer`。
- **星云粒子系统**：
  - 使用 `THREE.BufferGeometry` 和 `THREE.Points` 实现高性能渲染。
  - **位置分布**：利用数学公式（如高斯分布或球坐标系）生成约 5~10 万个粒子，使其呈现中间密集、边缘稀疏的“星云”形态。
  - **材质**：使用 `THREE.PointsMaterial`，开启 `additiveBlending`（加色混合）和 `transparent: true`，使粒子叠加处产生发光效果。
- **基础动画循环**：
  - 在 `requestAnimationFrame` 中，让整个粒子系统（或相机）缓慢旋转。

## 4. 交互逻辑开发 (长按汇聚)
- **事件监听**：在容器上绑定 `pointerdown`（按下）、`pointerup` 和 `pointerleave`（松开/离开）事件。
- **动画控制 (GSAP)**：
  - 定义两个核心变量：`rotationSpeed`（旋转速度）和 `convergenceFactor`（汇聚因子）。
  - **按下时**：使用 GSAP 将 `rotationSpeed` 加速，同时将 `convergenceFactor` 动画过渡到 1（粒子向中心 `0,0,0` 靠拢）。
  - **松开时**：使用 GSAP 将这两个变量恢复到初始状态。
- **阶段切换机制**：
  - 设定一个时间阈值（例如长按满 3 秒），当汇聚达到极限时，触发 `emit('complete')`，通知外层组件准备进入第二阶段（记忆星球）。

## 5. UI 提示层
- 使用 Tailwind CSS 在页面正下方添加“按住屏幕”的文字提示。
- 结合 `@vueuse/core` 或 CSS 动画，实现文字的呼吸闪烁效果，引导用户操作。
